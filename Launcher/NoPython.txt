找不到可用的 Python（需要 3.8 以上版本）。

────────────────────────────────────────

【方法一】免安裝版 Python（推薦，不需要系統管理員權限）

1. 到 python.org 下載「Windows embeddable package (64-bit)」，檔名類似 python-3.12.x-embed-amd64.zip。

2. 在本資料夾建立 Python 子資料夾。

3. 把 ZIP 內容解壓縮到 Python 子資料夾，使 Python\python.exe 存在。

4. 重新執行 Start.bat。

【方法二】安裝 Python 3.8 以上版本後重新執行 Start.bat。
